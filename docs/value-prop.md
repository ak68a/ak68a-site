## How I Work

1. **Measure twice, cut once.** I don't start building until the architecture is thorough enough that any engineer can pick up a ticket and know exactly what to build, what tests to write, and what security requirements apply.

2. **AI generates, I verify.** Claude Code writes the code. I architect the system, direct the AI, and verify every output - especially on money-path code where a rounding bug costs real money.

3. **Security is structural, not a checklist.** My agent pipeline has mandatory security requirements at every stage: the planner must specify them, the implementer must prove them with file:line citations, the reviewer must verify the citations are real. Security can't be "forgotten."

4. **I build teams that outlast me.** Architecture docs, protocols, agent tooling, and management frameworks mean the team keeps moving at the same quality bar whether I'm reviewing every PR or not.
